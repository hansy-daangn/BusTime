# 🚌 BusTime

**👉 위젯 열기: https://hansy-daangn.github.io/BusTime/**
🛠 개발자용(시나리오 탭·연결 설정 포함): https://hansy-daangn.github.io/BusTime/dev.html

서울 버스 실시간 도착 위젯. 설정한 시간대에만 자동 갱신하고, 도보 시간을 빼서 **"지금 나가세요"**를 알려줍니다. 기본: **9802 · 논현역**.

- 웹에서 실데이터가 안 뜨면 로컬에서 `python proxy.py` 한 번 실행 — 실데이터를 그대로 중계해 브라우저 차단(CORS)을 우회합니다.
- `main`에 머지되면 위 링크로 자동 배포됩니다.
