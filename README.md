# 🚌 BusTime — 버스 도착 플로팅 위젯

서울 버스 실시간 도착 정보를 화면 모서리 위젯으로 보여줍니다.
지정한 시간대(기본 07:30–09:30, 평일)에만 자동 갱신하고, 정류장까지 도보 시간을 넣어두면
**"지금 나가세요"** 타이머까지 알려줍니다. 기본 등록: **9802 · 논현역**.

## 바로 보기

| 링크 | 용도 |
|---|---|
| **[실제 결과물](https://claude.ai/code/artifact/360dae4b-32dc-4588-bcbb-dcb780bc4e7c)** | 위젯 실사용 화면 그대로 |
| **[개발자용 미리보기](https://claude.ai/code/artifact/8dbc8e83-e86d-4a0e-9623-701aa2c80baa)** | 하단 시나리오 탭으로 여유 → 접근 → 곧 도착 → 지금 나가기 → 놓침 → 자동 시연을 클릭 한 번씩 확인 |

두 링크는 수정될 때마다 같은 주소로 계속 갱신됩니다.

> ⚠️ 미리보기 페이지는 호스팅 보안 정책(CSP)상 외부 API 호출이 차단되어 **실데이터가 나오지 않습니다**
> (카드에 연결 오류가 뜨는 게 정상). 디자인·모션·시나리오 확인용이고, 실데이터는 아래 로컬 실행으로 확인하세요.

## 실데이터로 실행 (로컬)

```bash
git clone https://github.com/hansy-daangn/BusTime.git
cd BusTime
python proxy.py        # CORS 우회 프록시 (한 번 켜두면 끝)
```

그다음 `app.html`을 브라우저로 열면 됩니다. 서비스 키가 내장돼 있어 바로 실데이터가 나옵니다.

위젯처럼 띄우려면(주소창 없는 창):

```
chrome.exe --app="file:///C:/경로/BusTime/app.html"
```

## 구성

| 파일 | 역할 |
|---|---|
| `app.html` | 위젯 본체 — 노선·정류장 자동완성 등록, 활성 시간대, 나가기 타이머, 시나리오 탭 |
| `proxy.py` | 서울시 API CORS 우회 프록시 (표준 라이브러리만, `ws.bus.go.kr` 화이트리스트) |
| `index.html` | 랜딩 |
| `designs.html` | 디자인 탐색 기록 (최종: Aurora Minimal) |

## API · 트래픽 한도

- 데이터: `ws.bus.go.kr/api/rest` (서울시 버스도착정보). 기본·보조 서비스 키 2개 내장, 기본 키 실패 시 자동 전환.
- 기본 키(공공데이터포털)는 도착정보 기능당 **1,000회/일** 한도.
- 위젯은 **적응형 폴링**으로 한도를 아낍니다: 도착/출발 3분 이내 20초 · 10분 이내 30초 · 그 외 60초+.
  하단 상태바에 오늘 호출 수가 표시됩니다.
- 대략적 감: 활성 5시간 × 버스 1대 × 30초 균일 폴링 = 600회/일. 버스 N대면 주기를 30×N초쯤으로.
