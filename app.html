연결 구조

데이터는 항상 서울시 실 API(ws.bus.go.kr)에서 옵니다. proxy.py는 가짜 데이터가 아니라 실데이터를 그대로 중계하는 우회로예요 — 브라우저가 보안 정책(CORS)으로 API 직접 호출을 막을 때만 사용됩니다. 
python proxy.py
연결 모드 "자동"이면 직접 호출 실패 시 프록시로 자동 폴백.

트래픽 설계

기본 키는 도착정보 기능당 1,000회/일. 폴링: 도착·출발 3분 이내 60초 · 12분 이내 120초 · 그 외 240초. 4명 × 1노선 × 4시간 기준 일 사용량 ≈ 600회(60%). 기본 키 소진 시 보조 키로 자동 전환. 하단 상태바에 오늘 호출 수 표시.
