1. 서비스 키 · 일일 한도

키는 기본·보조 2개가 내장돼 있어 바로 실데이터가 나옵니다. 기본 키가 실패하면 보조 키로 자동 전환돼요.
기본 키(공공데이터포털)는 도착정보 기능당 1,000회/일 한도. 위젯이 도착·출발 임박 때만 촘촘히(20초), 멀 때는 느슨하게(60초+) 호출해 한도를 아낍니다. 하단 상태바에서 오늘 호출 수를 확인할 수 있어요.
본인 키로 바꾸려면: 공공데이터포털에서 "서울특별시_버스도착정보조회 서비스" 활용신청 → 발급 키를 설정에 교체.

2. 데이터가 안 나올 때

브라우저가 API 직접 호출을 막는 경우(CORS)입니다. 같이 있는 파일을 한 번만 실행하면 자동 폴백으로 해결됩니다. 
python proxy.py
연결 모드가 자동(기본)이면 직접 호출 실패 시 프록시로 알아서 우회합니다.
