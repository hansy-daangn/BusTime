1. 서비스 키 발급

  1. 서울 열린데이터 광장 로그인
  2. 검색: "버스도착정보" → 서비스 상세에서 인증키 신청
  3. 승인 즉시. 마이페이지에서 Encoding Key 복사 → 설정에 붙여넣기
위 노선/정류장 검색도 같은 키를 씁니다.

2. CORS 우회 · 로컬 프록시

같이 있는 파일을 한 번만 실행하면 됩니다. 
python proxy.py
설정에서 데이터 모드를 로컬 프록시로.

3. 창을 위젯처럼 띄우기

Chrome 앱 모드: 
chrome.exe --app="file:///C:/경로/app.html"
창 크기 380×620 정도로 줄이고 원하는 모서리에 배치.
항상 위 기능은 다음 단계(Electron/Tauri)에서.
