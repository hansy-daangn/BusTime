연결 구조

항상 실 API. 프록시·중계기 불필요.
  • 인천·경기(TAGO): apis.data.go.kr — HTTPS+CORS 허용, 브라우저 직접 호출 (실측 확인)
  • 서울 도착: ws.bus.go.kr(HTTP) — direct 실패 시 공용 릴레이(allorigins) 폴백
  • 서울 검색·정류소: 정적 스냅샷(내장 인덱스 718노선 + data/seoul/*.json) — API 0회
서울 도착정보는 키가 서울 인증서버에 등록 전파돼야 작동 (현재 대기, 매시간 자동 감시). 인천·경기 검색은 TAGO 버스노선정보/버스정류소정보 활용신청 승인 시 활성화.

트래픽 규칙

한도: 도착정보 기능당 1,000회/일 (키 공유 4명 가정).
  • 관심 시간대(기본 18:30–21:00, 10분 단위 설정) 안에서만 자동 갱신
  • 적응형 주기: 도착·출발 3분 이내 60초 · 12분 이내 120초 · 그 외 240초
  • 일일 900회 도달 시 자동 갱신 중지(안전 상한) · 수동 새로고침 15초 스로틀
  • 탭이 백그라운드면 호출 안 함 · 서울 노선 검색·정류소는 정적 데이터라 0회
2.5시간 창 기준 1인 최악 150회 → 4인 600회(60%). 하단 상태바에 오늘 호출 수 표시.
